# Documentation map

Documentation for `guide`, an MIT-licensed monorepo publishing two React packages: `@guide/core`,
a headless product-tour engine, and `@guide/mui`, its MUI rendering layer.

Read this file first, then the playbook relevant to your task. Contribution triggers are in
[AGENTS.md](../AGENTS.md).

## Decisions

[adr/index.md](adr/index.md) lists eleven records, `0001` to `0011`, plus [adr/template.md](adr/template.md).

- [0001](adr/0001-headless-core-and-rendering-layer.md) Split a headless core from the rendering layer
- [0002](adr/0002-logical-targets-via-data-attribute.md) Resolve targets by logical key, never by CSS selector
- [0003](adr/0003-delegated-navigation.md) Delegate navigation instead of depending on a router
- [0004](adr/0004-missing-target-policy.md) Wait for a missing target, then apply a policy
- [0005](adr/0005-disable-treeshake-to-keep-use-client.md) Keep treeshake disabled to preserve the use client banner
- [0006](adr/0006-support-two-mui-majors.md) Support two MUI majors and verify the second in CI
- [0007](adr/0007-pluggable-persistence-no-network.md) Persistence is an interface, and the packages make no network calls
- [0008](adr/0008-accessibility-in-the-core.md) Accessibility lives in the core, and interactive steps are non-modal
- [0009](adr/0009-typecheck-core-through-sources.md) Typecheck the MUI package against the core's sources
- [0010](adr/0010-shipped-package-readmes-exempt-from-frontmatter.md) Exempt the shipped package READMEs from the OKF frontmatter rule
- [0011](adr/0011-move-to-apollo-vision-labs.md) Move to the Apollo Vision Labs organisation

## Outside this bundle

Two pre-existing documents are the authoritative record of intent and execution for the current
codebase. They are left exactly where they are and carry no OKF frontmatter:

- `docs/superpowers/specs/2026-09-02-guide-onboarding-design.md`: the validated design.
- `docs/superpowers/plans/2026-09-02-guide-tour.md`: the implementation plan.

The per-package `CHANGELOG.md` files are generated by Changesets and are likewise not bundle
documents.
